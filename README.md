# Proyek

Pemrograman Mobile

## Deskripsi

Aplikasi latihan untuk pembelajaran dan pengembangan aplikasi mobile menggunakan Flutter.

## Pengembang

Nama panggilan / akun GitHub: Agus Martha Jaya

## Status

Proyek awal perkuliahan.

## Tujuan

Aplikasi ini dibuat sebagai proyek pembelajaran pemrograman mobile menggunakan Flutter. Tujuannya adalah untuk mempelajari proses pembuatan, pengembangan, dan pengelolaan aplikasi mobile.

## Rencana Fitur

Tiga fitur yang direncanakan dalam aplikasi ini adalah:

1. Menampilkan halaman utama aplikasi.
2. Menampilkan informasi atau konten aplikasi.
3. Menyediakan navigasi antarhalaman.

## Cara Menjalankan

Pastikan Flutter sudah terpasang dan dapat digunakan pada komputer.

Jalankan perintah berikut pada terminal di dalam folder proyek:

```bash
flutter pub get
flutter run
```

Perintah `flutter pub get` digunakan untuk mengambil dependency yang dibutuhkan oleh proyek. Selanjutnya, `flutter run` digunakan untuk menjalankan aplikasi pada perangkat atau emulator yang tersedia.

## Kendala Setup

Flutter sudah terpasang dan perintah flutter pub get berhasil dijalankan. Flutter juga berhasil mendeteksi perangkat Windows, Chrome, dan Edge.

Namun, saat mencoba menjalankan aplikasi menggunakan flutter run pada Windows, aplikasi belum dapat dijalankan karena Visual Studio toolchain belum tersedia. Oleh karena itu, setup untuk menjalankan aplikasi desktop Windows masih membutuhkan instalasi dan konfigurasi Visual Studio dengan komponen yang diperlukan untuk pengembangan Flutter Windows.
